## What is agenticArxiv?

agenticArxiv helps you read and understand scientific papers. It uses artificial intelligence to scan large documents and find specific answers to your questions. Instead of reading dozens of pages, you ask the system to summarize findings, extract data points, or compare methodologies across different research articles.

The system works by breaking down PDFs, indexing the information, and letting an intelligent model retrieve the right data. It performs searches across text to provide accurate, cited information. You do not need to understand programming to use this tool.

## 🛠️ How to Use the System

Once the application opens, you will see a clean dashboard. You can begin working by following these steps:

1. Import your PDFs. Click the "Add Files" button and select the research papers you want to analyze.
2. Wait for the green progress bar. The system reads the layout of your PDFs to understand tables, figures, and text.
3. Configure your settings. Choose how strict the system is with data retrieval.
4. Ask a question. Type a query in the chat box. For example, you can ask, "What is the primary conclusion of the second paper regarding carbon emissions?"
5. View the response. The system displays the answer and links directly to the section of the document where it found the information.

## 💡 Key Features of the App

This software includes tools designed for deep research:

- Layout Awareness: The system reads tables and diagrams alongside text. It does not lose context when a paper uses complex formatting.
- Hybrid Search: It blends word-based searching with meaning-based searching. It identifies papers even if you use synonyms that do not appear in the original text.
- Stateful Conversations: You can ask follow-up questions. The system remembers your previous queries as you explore a paper.
- Local Processing: By caching data locally, the application speeds up recurring searches on the same dataset.
- Verified Citations: Every answer includes a link to the source page. You can click these links to verify the facts yourself.

## 🔧 Troubleshooting Common Issues

If the application fails to launch or encounters an error, try these fixes:

- Check your connection: The system requires an active web connection to reach the language models. Ensure your firewall allows the application to access the internet.
- Clear the cache: If you uploaded many files and the system feels slow, use the "Clear Cache" option in settings. This resets the temporary storage but keeps your imported papers.
- Restart the service: If the chat stops responding, close the app fully and relaunch it. This refreshes the underlying background tasks.
- Reinstall: If a file becomes corrupted, download the latest version again from the link provided above and install it over the current version.

## 🛡️ Privacy and Data

Your documents remain your property. When you process a paper, the system breaks it into small pieces of text to analyze them. You maintain control over your document collection within the folder structure of your local machine.
